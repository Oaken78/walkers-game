children, and PlayerHurtbox stops reading the Chassis mesh. Nothing on screen or in any metric changes.

## Work items
1. `socket_transform(socket_id: StringName) -> Transform3D` in walker-local space for all 11 sockets, mounted or free.
   A mounted leg socket is today's hip position. A free leg socket is where `socket_anchors.gd` puts its marker today.
   A top socket is today's `_top_spot`. Document the basis (for example +Y out of the face). An unknown id gives
   `push_error` and the identity transform. Positions follow `apply_build` exactly as today (in M0 the hips re-space
   by leg count). The block-layout table and fixed slots wait for M1's block chassis; the id is the only contract.
2. `top_mounts() -> Dictionary` (socket id -> the drawn top part) and `draw_cannons: bool = true`. WeaponRig sets the
   flag instead of hiding `Tops` children.
3. `chassis_size() -> Vector3` and `chassis_center() -> Vector3` (walker-local). PlayerHurtbox, the workshop and the
   test scripts use them instead of `get_node("Chassis")`.
4. `apply_build(build: WalkerBuild, allow_invalid: bool = false)`. With `allow_invalid` it draws a build that
   `is_valid()` rejects (too few legs, over load) without errors; the default keeps today's refusal. The workshop's
   `DisplayBuild` subclass goes away.
5. Read-only accessors for what `gait_course.gd` reads privately (`_hang_wait`, `_contact_count`).
6. `stats()["climb"]` already exists: no change.
